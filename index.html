📖 使用教程
1
打开供应商网站注册
选择您需要的供应商，点击卡片上的链接跳转至对应平台完成账号注册
2
创建 API Key
登录后进入控制台，在 API 管理页面创建新的 API 密钥并妥善保存
3
复制 TS 文件链接
在本页面供应商卡片上点击「复制」按钮，获取供应商配置文件的完整 URL
4
打开软件导入
启动 ToonFlow 客户端，在供应商管理中粘贴链接并填入 API Key 即可使用
